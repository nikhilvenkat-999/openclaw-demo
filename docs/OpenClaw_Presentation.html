How It Works

1
User Sends Message - "@OpenClaw check pipeline status"
2
Intent Detection - Keywords analyzed, "pipeline" detected
3
Skill Routing - Routes to Pipeline Monitor skill
4
Skill Execution - Checks pipeline data, gathers status
5
LLM Processing - Ollama formats response naturally
6
Response Delivered - Formatted status sent to Discord
